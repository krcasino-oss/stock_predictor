뉴욕 --:-- 한국 --:-- -
파일을 직접 열면 유튜브 재생이 막힐 수 있습니다. Termux에서 node server.js 실행 후 표시되는 주소(http://127.0.0.1:3200)로 접속하세요.
자막 크기
추가한 채널은 이 브라우저에 저장됩니다. @핸들은 임베드가 불가해 유튜브에서 열립니다.
❓ 한글 자막이 안 나올 때 / 재생이 안 될 때
  • 이 화면은 유튜브 플레이어에 한국어 자막 → 없으면 영어 자막을 한국어로 자동번역하도록 요청합니다. 단, 라이브 방송의 자동번역 자막은 유튜브 정책상 채널·방송마다 제공 여부가 다릅니다. 자막 자체가 없는 방송이면 번역도 나오지 않습니다.
  • 자막이 안 나오면 플레이어의 ⚙ 설정 → 자막 → 자동 번역 → 한국어를 직접 선택해 보세요.
  • "동영상을 재생할 수 없음(오류 150/101)"은 방송사가 외부 재생(임베드)을 막은 경우입니다. ‘유튜브에서 열기’ 버튼으로 유튜브 앱에서 보시고, 앱의 자막(CC) → 자동 번역 → 한국어를 켜세요.
  • "현재 라이브 방송이 없습니다"가 나오면 해당 채널이 지금 생방송 중이 아닌 것입니다. CNBC는 보통 미국 장중(한국 밤 시간)에 생방송을 합니다.
